# Chrome Web Store 제출 문안

## 기본 정보

- 이름: `온글 번역 — 브라우저 로컬 AI`
- 요약: `웹페이지 본문, 선택한 텍스트와 YouTube 자막을 브라우저 안에서 한국어로 번역하고 읽어줍니다.`
- 카테고리: 생산성
- 개인정보처리방침 URL: `https://github.com/ledzpl/local_translator/blob/main/PRIVACY_POLICY.md`

## 상세 설명

온글 번역은 외국어 웹페이지를 읽는 흐름을 끊지 않도록 현재 페이지 안에 한국어 번역을 표시하는 로컬 AI 번역 확장 프로그램입니다.

- 팝업에 붙여넣은 텍스트를 한국어로 번역
- 현재 페이지 본문 아래에 한국어를 표시하고 한 번에 복원
- 선택 텍스트를 우클릭 또는 단축키로 바로 번역
- 사용자가 켠 경우 YouTube의 화면 자막을 한국어로 표시
- 번역한 한국어를 브라우저 안의 AI 음성 모델로 재생
- 번역할 내용과 결과를 번역 서버로 보내지 않음

첫 번역과 첫 듣기 때 Hugging Face에서 고정된 버전의 모델 파일을 내려받습니다. 기본 TranslateGemma 4B 번역 모델은 약 3.1GB이며 WebGPU가 필요합니다. WebGPU를 사용할 수 없거나 실패하면 M2M100 WASM 약 650MB를 추가로 내려받을 수 있습니다. 초기화에 실패한 WebGPU 가중치는 확장 캐시에서 정리하고 성공한 경로의 모델을 재사용합니다. 모델 준비에는 연결 속도와 기기 성능에 따라 수 분이 걸릴 수 있습니다. YouTube 자막 번역과 자막 자동 켜기는 사용자가 데이터 처리 안내를 확인한 뒤 직접 켤 수 있습니다.

## 단일 목적

사용자가 보고 있는 외국어 텍스트·웹페이지 본문·YouTube 자막을 브라우저 안의 AI 모델로 한국어 번역하고, 그 한국어 번역을 브라우저 안에서 읽어주는 것입니다.

## 권한 설명

- `activeTab`: 사용자가 페이지 번역·선택 번역을 요청한 현재 탭에만 접근합니다.
- `scripting`: 사용자 요청 시 현재 일반 웹페이지에 로컬 content script를 삽입합니다.
- `contextMenus`: 선택 텍스트의 우클릭 번역 메뉴를 제공합니다.
- `offscreen`: DOM이 없는 서비스 워커 대신 로컬 번역·음성 모델과 오디오 재생을 실행합니다.
- `storage`: 데이터 처리 안내 확인과 모델·언어·자막 설정을 Chrome 동기화 저장소에 보관합니다.
- `https://www.youtube.com/*`: 사용자가 자막 번역을 켠 경우 화면에 표시되는 YouTube 자막을 읽고 번역을 표시합니다.
- Hugging Face 호스트: 번역/TTS 모델의 설정·토크나이저·가중치 데이터만 HTTPS로 내려받습니다. 사용자 텍스트는 전송하지 않습니다.

## 개인정보 탭

- Remote code: `No, I am not using remote code.`
- 처리 데이터 유형: `Website content`
- 판매·광고·신용평가·목적 외 사용: 모두 `No`
- Limited Use 인증: 모든 항목 확인
- 웹 탐색 기록: 수집하지 않음. 사용자가 요청한 현재 페이지 내용과 켠 동안 보이는 자막만 기능 제공에 필요한 순간 처리

## 리뷰어 테스트 안내

1. 설치 후 팝업을 열고 데이터 처리 안내의 체크박스를 선택한 뒤 `동의하고 시작`을 누릅니다.
2. 팝업에 영어 문장을 입력하고 `한국어로 번역`을 누릅니다.
3. 첫 실행은 약 3.1GB TranslateGemma 모델을 내려받아 수 분 이상 걸릴 수 있습니다. WebGPU 폴백이 발생하면 M2M100 WASM 약 650MB를 추가로 내려받습니다.
4. 번역 결과의 `듣기`를 누르면 약 400MB Supertonic 3 음성 모델과 기본 음성 스타일을 한 번 내려받습니다.
5. 일반 HTTPS 페이지에서 `페이지 안에 한국어 표시`와 복원을 확인합니다.
6. YouTube 설정을 직접 켠 뒤 자막이 있는 영상에서 한국어 오버레이를 확인합니다.

계정이나 테스트 자격 증명은 필요하지 않습니다. 모델 다운로드 외에 개발자 서버와 통신하지 않습니다.
